# UKAY — Good clothes live twice.

Secondhand marketplace landing (bidding + live auctions). UI/UX exam build.

## Run
Any static server:
```
npx serve . -l 3000
# or
python3 -m http.server 3000
```

## Deploy (Vercel)
```
npx vercel --prod
```
No build step — static. `vercel.json` included.

## GitHub
```
git init && git add -A && git commit -m "UKAY landing - exam" && git push
```

Mock data only, no backend.
